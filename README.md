# DeskPause

DeskPause is a small Windows tray app for stepping away while Codex Computer Use keeps working on your visible desktop. Press a shortcut to block ordinary physical mouse and keyboard input. Type your seven-digit PIN to take control again.

**[Download DeskPause 1.1.0 for Windows x64 (portable ZIP)](https://github.com/DJ-Tribefull/DeskPause/raw/refs/heads/main/downloads/DeskPause-1.1.0-win-x64.zip)** · [SHA-256 checksum](https://github.com/DJ-Tribefull/DeskPause/blob/main/downloads/DeskPause-1.1.0-win-x64.zip.sha256)

## Get started

1. Extract the ZIP into a folder of your choice and open **DeskPause.exe**. It runs as a standard user on **x64 Windows with .NET Framework 4.8 or later**. The portable executable is unsigned.
2. Choose a shortcut and enter the same seven-digit PIN in both fields. The suggested shortcut is **Ctrl+Alt+F9**. Leading zeroes work. Choose a PIN specifically for DeskPause.
3. Select **Save**, then press and release your shortcut. When the teal tray icon turns into an amber padlock, DeskPause is armed. If the icon is hidden, open the taskbar’s tray overflow.
4. To resume, type the PIN on the physical keyboard and release the keys. Use the number row or the numpad with **Num Lock** on. The digits stay out of the focused app. You can leave the mouse pointer wherever it is.

The shortcut picker includes punctuation and separate numpad keys. For **Ctrl+/** on a US keyboard, select **Ctrl** and **/**. For **Ctrl+Shift+/**, also select **Shift**. If Windows has already assigned your combination, the settings window lets you choose another.

## Try it before stepping away

Open **Test in a window** from the tray menu. For two minutes the filter applies inside that window. Ask Codex to click **Test click** and type a phrase into the text field. The counter and the text let you see whether automation works on your setup. You can also launch this check with `DeskPause.exe --input-check`.

For a desktop-wide check, open a blank text editor, arm DeskPause, and try a physical click and **Alt+Tab**. Type the PIN and confirm that control returns and the editor contains no PIN digits.

## PIN entry and recovery

**Backspace** removes the last digit. **Escape** clears the entry. A gap of more than ten seconds between keystrokes clears a partial entry. Five incorrect complete attempts request the Windows lock, which can pause desktop automation.

**Forgotten PIN:** Press **Ctrl+Alt+Delete**, choose **Lock**, and sign back into Windows. DeskPause disarms when Windows reports that your session was unlocked. Open **Settings** in the tray menu to choose a new PIN. When changing only your shortcut, leave both PIN fields blank.

## Moving, updating, or removing DeskPause

The executable is portable and has no companion runtime files. Your shortcut and salted PIN verifier live in `%LOCALAPPDATA%\DeskPause\settings.dat`, protected by Windows for your user account. The app records no keystroke log. Moving the EXE to another folder on the same PC preserves your settings. On another PC or Windows account, choose your shortcut and PIN again.

To update, disarm DeskPause, choose **Exit** from its tray menu, replace the EXE, and launch it. To remove it, exit and delete the EXE. To remove your saved configuration as well, delete the DeskPause folder under `%LOCALAPPDATA%`. DeskPause installs no service, driver, or startup task.

## What the guard covers

DeskPause helps prevent casual interaction with an unlocked PC. Anyone nearby can still read the monitors. Windows-marked injected keyboard and mouse events pass through, including events generated by other automation software. The filter applies to ordinary keyboard and mouse input on the interactive desktop. Touch, pen, game controllers, raw device input, elevated apps, and Windows security screens fall outside its guarantee. Use the Windows lock for authentication or screen privacy.

DeskPause leaves Windows lock and sleep policies in effect. If Windows locks or the PC sleeps, DeskPause cannot keep Windows Computer Use active. [OpenAI’s Computer Use guide](https://learn.chatgpt.com/docs/computer-use)

## Build and test

From PowerShell in the repository root, run the following on x64 Windows with .NET Framework 4.8 or later. The scripts use the Windows .NET Framework C# compiler and have no NuGet dependencies.

```powershell
.\source\build.ps1
.\tests\test.ps1
```

The build writes **DeskPause.exe** to the repository root. Exit that copy before rebuilding it. The automated checks exercise PIN validation and editing, protected settings, and how the input filter handles physical and injected events. They use synthetic input and temporary test settings. To exercise Codex with the actual Windows hooks, use **Test in a window**.
